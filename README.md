# Portfolio Project

一个基于 Vue 3 + Vite 的个人作品集网站，支持 GitHub Actions 自动部署。

## 功能特性

- 📸 作品展示
- 👤 个人简介
- 📝 简历展示
- 📧 联系表单
- 🔐 后台管理系统

## 技术栈

- 前端：Vue 3 + Vite
- 后端：Express + SQLite
- 部署：GitHub Actions + Nginx

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建
npm run build
```

## 自动部署

推送代码到 `main` 分支会自动触发部署到服务器。
